# API курьеров

Для всех запросов передавайте заголовок `X-API-Token` со значением `COURIER_ORDERS_API_TOKEN` из `.env`.

## Список курьеров

`GET /api/users?limit=20&page=1`

`limit` необязателен: от 1 до 100, по умолчанию 20. Ответ содержит массив курьеров и метаданные пагинации. Поле хэша пароля не возвращается.

```json
{
  "data": [
    {
      "id": 1,
      "login": "aleks",
      "email": "aleks@example.test",
      "phone": "+79990000001",
      "created_at": "2026-09-13T19:06:19+00:00",
      "updated_at": "2026-09-13T19:06:19+00:00"
    }
  ],
  "meta": {
    "total": 4,
    "limit": 20,
    "current_page": 1,
    "last_page": 1
  }
}
```

## Создание курьера

`POST /api/users`

```json
{
  "login": "petr",
  "email": "petr@example.test",
  "phone": "+79990000005",
  "password": "Safe-password-2026"
}
```

Все поля обязательны. Логин, email и телефон должны быть уникальны; пароль — не менее восьми символов. В ответе `201 Created` возвращаются данные созданного пользователя без пароля и его хэша. Ошибки валидации возвращают `422`, неверный API-токен — `401`.
